# SZWebsiteClaude

## Location integrations

Location hours are managed through Marqii and rendered dynamically from its
public hours API. The site requests only the `hours` widget payload and renders
the schedule with native components; it does not load Marqii's widget script.

## Location directory

The native location directory lives in `src/locations.ts`. Add each store there
with its address, map coordinates, and Marqii embed ID. Marqii remains the live
source for business hours, so schedule changes do not require a site release.

## CMS access and roles

Store management at `/admin/stores` fails closed until Supabase Auth is
configured. Copy `.env.example` to `.env`, provide the project URL and
publishable key, and apply `supabase/migrations/202607280001_cms_roles.sql`.

CMS permissions:

- `admin`: manage stores, delete records, and assign user roles
- `editor`: create and update stores
- `viewer`: read-only store access

The browser uses only the publishable key. Role checks and store-write policies
are enforced by database functions and row-level security; never place a
service-role key in the website environment.

The first administrator must be assigned from the Supabase SQL editor or other
trusted server-side process. Public sign-up does not grant a CMS role.
